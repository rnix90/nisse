# Nunito

The Nisse brand typeface. Rounded sans-serif, close to the drawn wordmark we picked.

- Files: `Nunito[wght].ttf` and `Nunito-Italic[wght].ttf`, variable fonts, weight 200-1000.
  Both are unmodified copies from the upstream Google Fonts repository
  (`ofl/nunito` in github.com/google/fonts).
- License: SIL Open Font License 1.1, see `OFL.txt`. Copyright 2014 The Nunito Project Authors.
  No Reserved Font Name is declared.
- The logo wordmark uses weight 800 (ExtraBold), outlined by `tools/logo/build.py`.

## Using it in the distro

- Install to `/usr/share/fonts/truetype/nunito/` and ship `OFL.txt` alongside.
- Fine for UI text, installer, website and documents. Do not sell the font on its own and
  keep the license text with any redistribution. Embedding in documents is allowed.
- The OFL covers the font files only. The rest of the repo stays GPL-2.0-or-later.
