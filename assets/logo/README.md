# Nisse logo

The mark is the nisse's cap peeking over a hill, in a disc. The cap shape comes from the
wordmark (the cap on the i in the original sketch).

| File | Use |
|---|---|
| `nisse-icon.svg` | 1:1 round icon, dark, for light backgrounds |
| `nisse-icon-reverse.svg` | 1:1 round icon, light, for dark backgrounds |
| `nisse-lockup.svg` | icon + wordmark, horizontal, dark |
| `nisse-lockup-reverse.svg` | icon + wordmark, horizontal, light |

- Colours: ink `#1b2330`, paper `#f6f2e9`.
- The cap and hill line are real transparency (SVG mask), so the mark works on any background.
- The terminal-under-the-cap sketch from the logo exploration is reserved for the distro's
  terminal app, not the main logo.
